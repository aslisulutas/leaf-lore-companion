# Leaf Lore Companion

Bana bir bitki türünü tanımlayabileceğim web tabanlı bir mobil uygulama yapmak istiyorum.  Bu uygulamada amacım fotoğrafını çektiğimiz veya fotoğrafını yüklediğimiz bitkinin türünü belirlemek ve görselini görmek. Aynı zamanda bitkinin bakım, sulama gibi daha birçok özelliğini gösterebileceğimiz bir mobil uygulama. API key kullanacağım. Gemini olacak.
